# taekidamoa

유튜브 채널 [@태기tp](https://www.youtube.com/@%ED%83%9C%EA%B8%B0tp/shorts)와 함께 운영하는 홈페이지입니다.

## 페이지 목록

| 주소 | 파일 | 내용 |
| --- | --- | --- |
| `/` (첫 화면) | `index.html` | **안전과 사람** — 생활 안전 수칙, 안전 점검, 안전 다짐 게시판, 긴급 연락처 |
| `/안전과사람/` | `안전과사람/index.html` | 예전 주소. 첫 화면으로 자동 이동 |
| `/로또번호/` | `로또번호/index.html` | 로또 번호 추천기 (6개 번호 × 5세트) |

## 기타 파일

- `og-image.png` — 카카오톡·SNS에 링크를 공유할 때 뜨는 미리보기 이미지 (1200×630)

## 외부 연동

- **Supabase** — 안전 다짐 게시판 글과 방문자 수를 저장합니다. 방문자 수는 누적 100명이 넘어야 화면에 표시됩니다.

## 수정할 때 참고

- 안전 페이지 내용은 `index.html` 하나만 고치면 됩니다. `안전과사람/` 폴더는 이동용이라 손댈 필요가 없습니다.
- 사이트 주소가 바뀌면 `index.html` 상단의 `og:url`, `og:image` 주소도 함께 바꿔야 미리보기가 정상적으로 나옵니다.
