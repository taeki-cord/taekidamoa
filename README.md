# taekidamoa

유튜브 채널 [@태기tp](https://www.youtube.com/@%ED%83%9C%EA%B8%B0tp/shorts)와 함께 운영하는 홈페이지입니다.

## 페이지 목록

| 주소 | 파일 | 내용 |
| --- | --- | --- |
| `/` (첫 화면) | `index.html` | **안전, 그리고 우리 가족** — 이달의 안전, 생활 안전 수칙, 안전 점검, 안전 다짐 게시판, 쇼츠 영상, 긴급 연락처, 행운 번호 뽑기 |
| `/안전과사람/` | `안전과사람/index.html` | 예전 주소. 첫 화면으로 자동 이동 |
| `/로또번호/` | `로또번호/index.html` | 예전 주소. 첫 화면의 '행운 번호' 코너로 자동 이동 |

## 기타 파일

- `og-image.png` — 카카오톡·SNS에 링크를 공유할 때 뜨는 미리보기 이미지 (1200×630)

## 외부 연동

- **Supabase** — 안전 다짐 게시판 글과 방문자 수를 저장합니다. 방문자 수는 누적 100명이 넘어야 화면에 표시됩니다.

## 수정할 때 참고

- 안전 페이지 내용은 `index.html` 하나만 고치면 됩니다. `안전과사람/` 폴더는 이동용이라 손댈 필요가 없습니다.
- 사이트 주소가 바뀌면 `index.html` 상단의 `og:url`, `og:image` 주소도 함께 바꿔야 미리보기가 정상적으로 나옵니다.
- 쇼츠 영상은 `index.html`의 `<div class="shorts">` 안에 썸네일 스타일 카드로 들어가 있고, 카드를 누르면 그 자리에서 재생됩니다. 새 영상을 걸 때는 `<button class="short">` 한 덩어리를 복사해서 `data-id`(영상 ID), 코너 이름, 제목만 바꾸면 됩니다. 제목에서 `<em>…</em>`으로 감싼 글자는 노란색으로 나옵니다. 영상 ID는 유튜브 스튜디오 주소 `studio.youtube.com/video/영상ID/edit`에서 확인할 수 있습니다.
- **주인 모드:** 사이트 주소 끝에 `?owner=on`을 붙여 한 번 접속하면, 그 기기·브라우저는 방문자 수 집계에서 빠지고 방문자 수가 항상 보입니다. 해제는 `?owner=off`. 휴대폰·PC·브라우저마다 따로 한 번씩 켜야 합니다.
- **이달의 안전:** 한국 시간 기준으로 달이 바뀌면 그 달 수칙이 자동으로 나옵니다(1~12월 12개 미리 입력). 문구를 바꾸려면 `index.html` 아래쪽 `const seasons = {` 에서 해당 달 줄만 고치면 됩니다.
- **로또 추첨 D-day:** 행운 번호 코너 위에 "이번 주 추첨까지 N일 남았습니다"가 뜨고, 토요일 추첨(저녁 8시 35분) 전까지는 "오늘 저녁 추첨!"으로 바뀝니다. 추첨이 끝나면 다음 주 기준으로 넘어갑니다.
- **공유 버튼:** 안전 점검 결과 아래와 맨 아래에 있습니다. 공유 링크 끝에는 `?from=share`가 붙어서, 공유로 들어온 방문이 따로 집계됩니다.
- **방문 경로 표시:** 주소 끝에 `?from=yt`(유튜브), `?from=share`(공유)를 붙이면 경로별로 집계됩니다. 나머지는 검색·직접·기타로 자동 분류됩니다.

## 검색 등록

- `sitemap.xml` — 검색 사이트에 페이지 목록을 알려주는 파일입니다. 주소: `https://taeki-cord.github.io/taekidamoa/sitemap.xml`
- 네이버 서치어드바이저·구글 서치콘솔에서 받은 확인 코드는 `index.html` 상단의 `naver-site-verification`, `google-site-verification` 줄에 넣습니다.
- `robots.txt`는 사이트 주소의 맨 앞(`taeki-cord.github.io/robots.txt`)에만 둘 수 있어서 이 저장소에는 만들지 않았습니다. 없어도 검색 등록에는 문제가 없습니다.
