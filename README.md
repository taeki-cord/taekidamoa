# taekidamoa

| --- | --- | --- | --- |

## 페이지 만들기 (`tools/build.py`)

사고 글·월별 수칙·점검표·사이트맵은 `tools/content.py` 내용으로 자동 생성됩니다. 내용을 고친 뒤 저장소 맨 위 폴더에서:

```
python tools/build.py
```

- 만들어진 `cases/`, `season/`, `checklist/` html 을 직접 고치면 다음 빌드 때 덮어써집니다. 꼭 `content.py` 에서 고치세요.
- 위쪽 메뉴와 맨 아래 꼬리말은 모든 페이지에 똑같이 들어갑니다. `index.html` 과 `로또번호/index.html` 에서는 `<!-- @header -->`, `<!-- @footer -->` 표시 사이를 빌드가 채웁니다.
- 첫 화면의 사고 카드 6개(`CASES` 앞쪽 6개)와 쇼츠 카드 4개(`HOME_SHORTS`)도 빌드가 채웁니다.
- **새 쇼츠를 올렸을 때:** `CASES` 맨 위에 한 덩어리를 복사해 넣고 영상 ID·제목·내용을 바꾼 뒤 빌드 → 글 페이지·목록·첫 화면·사이트맵이 한 번에 바뀝니다. 영상 ID는 유튜브 스튜디오 주소 `studio.youtube.com/video/영상ID/edit`에서 확인할 수 있습니다.
- 디자인은 `assets/site.css`, 공유 버튼·쇼츠 카드·방문자 수는 `assets/site.js` 에 모여 있습니다.

## 수정할 때 참고

- 사이트 주소가 바뀌면 `index.html` 상단의 `og:url`, `og:image` 주소도 함께 바꿔야 미리보기가 정상적으로 나옵니다.
- **주인 모드:** 사이트 주소 끝에 `?owner=on`을 붙여 한 번 접속하면, 그 기기·브라우저는 방문자 수 집계에서 빠지고 방문자 수가 항상 보입니다. 해제는 `?owner=off`. 휴대폰·PC·브라우저마다 따로 한 번씩 켜야 합니다.
- **이달의 안전:** 한국 시간 기준으로 달이 바뀌면 첫 화면에 그 달 수칙이 자동으로 나옵니다. 문구는 `tools/content.py` 의 `SEASONS` 에서 고치고 빌드하세요.
- **로또 추첨 D-day:** 행운 번호 페이지 위에 "이번 주 추첨까지 N일 남았습니다"가 뜨고, 토요일 추첨(저녁 8시 35분) 전까지는 "오늘 저녁 추첨!"으로 바뀝니다. 추첨이 끝나면 다음 주 기준으로 넘어갑니다.
- **공유 버튼:** 모든 페이지 맨 아래와 글·점검표 중간에 있습니다. 지금 보고 있는 페이지 주소 끝에 `?from=share`가 붙어서, 공유로 들어온 방문이 따로 집계됩니다.
- **방문 경로 표시:** 주소 끝에 `?from=yt`(유튜브), `?from=share`(공유), `?from=blog`(블로그)를 붙이면 경로별로 집계됩니다. 나머지는 검색·직접·기타로 자동 분류됩니다. 유튜브 채널 링크·블로그 글에 넣는 주소에는 꼭 `?from=yt`, `?from=blog`를 붙이세요. 사이트 안에서 페이지를 옮겨 다닌 건 새 방문으로 세지 않습니다.
